# Список модов Starsector по категориям

---

## 1. Библиотеки и зависимости

| Мод                 | Кратко                                                  |
| ------------------- | ------------------------------------------------------- |
| **LazyLib**         | Базовая библиотека, нужна многим модам.                 |
| **MagicLib**        | Библиотека для скриптов, миссий и систем модов.         |
| **LunaLib**         | Меню настроек модов внутри игры.                        |
| **GraphicsLib**     | Улучшенные визуальные эффекты, свет и шейдеры.          |
| **Particle Engine** | Система частиц для оружия, двигателей и эффектов.       |
| **AshLib**          | Вспомогательная библиотека для некоторых крупных модов. |

---

## 2. Глобальная кампания и стратегический слой

| Мод                            | Кратко                                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------------------- |
| **Nexerelin**                  | Главный глобальный мод: войны, захват рынков, дипломатия, альянсы и колонизация NPC-фракциями.        |
| **Starlords_Temp-master**      | Добавляет лордов/командиров и больше политико-военного слоя. Может быть нестабильным.                 |
| **SecondInCommand**            | Переделывает систему развития через офицеров и специализации. Сильно влияет на кампанию и билд флота. |
| **SecondInCommand_Dustkeeper** | Аддон к SecondInCommand. Добавляет совместимость или контент под отдельную специализацию.             |
| **Starship Legends**           | Корабли получают репутацию, бонусы, штрафы и историю после боёв.                                      |

---

## 3. Колонии, экономика и строительство

| Мод                                               | Кратко                                                                                   |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Industrial.Evolution4.1.b**                     | Новые постройки, индустрии, объекты и механики колоний. Хороший колониальный эндгейм.    |
| **Terraforming and Station Construction v10.0.5** | Терраформинг планет, строительство станций и крупных объектов.                           |
| **Terraforming Made Easy 2.8.4c**                 | Упрощает терраформинг, делает развитие планет менее душным.                              |
| **Building Menu Overhaul**                        | Улучшает меню построек колоний: удобнее искать и выбирать здания.                        |
| **Demand Indicators1.0f**                         | Показывает спрос, дефицит и избыток товаров на рынках. Полезно для торговли и экономики. |

| **Xhan Empire-3.0.1**                             | Полноценная новая фракция со своими кораблями, оружием, станциями и стилем.           |

## 7. QoL, интерфейс и удобство

| Мод                               | Кратко                                                                              |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| **QoLPack**                       | Набор мелких улучшений качества жизни.                                              |
| **Refit Filters-3.1.3**           | Фильтры в экране сборки корабля. Удобнее искать оружие и hullmods.                  |
| **Scan Those Gates-1.5.8**        | Упрощает работу с гейтами и их поиском/сканированием.                               |
| **SpeedUp-1.2.2**                 | Ускорение времени. Очень полезно в бою и кампании.                                  |
| **stelnet / Stellar Networks**    | Поиск товаров, рынков, контактов и информации по сектору. Один из лучших QoL-модов. |
| **Too Much Information**          | Показывает больше скрытых статов кораблей, оружия и крыльев.                        |
| **Bigger Recoveries**             | Больше кораблей можно восстановить после боя.                                       |
| **Fleet Size By DP-1.0.3**        | Лимит флота считается по DP, а не просто по количеству кораблей.                    |
| **Detailed Combat Results-5.4.2** | Подробная статистика после боя: урон, вклад кораблей и эффективность оружия.        |
| **Combat Chatter**                | Реплики и переговоры в бою. Больше атмосферы.                                       |
